# ===========================================================================
# 额外 feed 清单 —— 「预检说包找不到」时的第一处理方案
#
# 每行一个 feed，空格分隔：  名字  URL  [第三列]
#   · 第三列写 flatten=xxx  ：该仓库不是标准 feed 布局（包埋在子目录里），
#                             把 xxx/ 下的包目录摊平到 package/
#   · 第三列写其它内容      ：当作分支，等价于 feeds.conf 里的 ;分支
#   · 行首 # 是注释
#
# 加完之后，把要装的包名写进 config/packages.txt。
# diy-part1.sh 会读这个文件，重复执行安全（同名 feed 只更新 URL）。
#
# ⚠️ 这里只放「单个包的仓库」。不要把另一个发行版（ImmortalWrt / 官方 OpenWrt）
#    的 luci + packages 整个加进来：feeds install -a 先到先得，重叠的包会被
#    本地源码抢先、加了等于没加；非重叠包的依赖又常常在本树里不存在。
#    要换发行版请改「源码仓库」（见 README「换源码仓库」）。
# ===========================================================================
