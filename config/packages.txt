# 语法（比手写 CONFIG_PACKAGE_xxx=y 简单得多）：
#   每行一个包名，可以带空格和注释
#   行首加 ! 表示「显式关掉」（对应 .config 里的 "# CONFIG_PACKAGE_x is not set"）
#   以 # 开头是注释，整行忽略
#   名字就是 opkg/apk 里的包名，也是 feeds 里目录名：luci-app-xxx / kmod-xxx / 本体名
#
# 改完直接点 Actions → Run workflow 就行，脚本会自动拼成 openwrt/.config，
# 并在编译前用 5 秒告诉你「这些包在 feed 里找不到」，不用等 1 小时 45 分。
# ===========================================================================
